# ADR-0001：打分权重以评分任务快照为准

## Status

Accepted

## Date

2026-09-22

## Context

一个员工可以由多个打分人评分。系统此前将所有打分人总分做等权平均，无法表达不同打分人的业务重要性。权重不能在评分过程中改变，否则已经提交或导出的结果会失去可追溯性。

## Decision

管理员在草稿周期为每个“周期、被打分人、打分人”关系设置百分比权重。每组关系合计必须为 100.00，发布后冻结。

管理员审核通过并生成评分任务时，系统将该权重写入 `score_tasks`。最终分只基于已提交评分任务中的快照权重计算：

`finalScore = round(sum(task.totalScore * task.weight / 100), 2)`。

## Consequences

- 历史考核结果可复核，未来修改配置不会影响已创建的评分任务。
- 导出明细能够展示权重、打分人总分和加权贡献。
- 权重配置需要在发布前完成，并参与发布校验。
- 旧数据需要在迁移时以确定性的均分规则回填。
