# 部门职级打分权重预设

## 目标与范围

管理员可为每个子公司下的部门保存一套职级系数。给员工配置打分人时，系统按**被打分人所在部门**的预设和**本次选中的打分人**职级，计算每人的百分比权重。管理员仍可逐人手动调整，最终保存的权重须合计 100.00%。

职级独立于职位，固定为员工、副总经理、总经理；职位仍为自由文本。现有员工默认职级为员工，不推断其职位中的字样。

## 业务规则

- 预设按 `(子公司, 部门)` 唯一，三个系数均为 1–100 的正整数；首次设置建议值为总经理 3、副总经理 2、员工 1。
- 计算分母为选中打分人的系数之和。每位打分人分得 `个人系数 ÷ 分母 × 100%`，保留两位小数；余数以确定性顺序分配，确保合计恰为 100.00%。
- 例如选中 1 位总经理、2 位副总经理、3 位员工，使用 3:2:1 时，每人分别为 30%、20%、10%。未被选中的部门员工不计入分母。
- 新建/修改打分关系时，有部门预设则可自动计算；没有预设仍采用精确均分。管理员可以手动改动，提交前仍需通过总和校验。
- 调整预设或职级不会改动已经保存的打分关系；草稿期可重新应用预设。发布后关系冻结，审核生成的评分任务继续保存权重快照。
- 仅拥有目标子公司管理权限的管理员可读写该部门预设和员工职级；跨子公司同名部门互不影响。

## 接口与数据

- 员工数据增加 `rank`：`EMPLOYEE`、`DEPUTY_GENERAL_MANAGER`、`GENERAL_MANAGER`。新增、编辑、Excel 导入导出、状态接口都包含此字段；旧版 Excel 缺失该列时按 `EMPLOYEE` 导入。
- 新增部门预设保存接口，接收子公司、部门和三个系数；状态接口仅向相应管理员返回可见预设。
- 打分关系保存接口支持 `weightMode=DEPARTMENT_PRESET` 配合打分人工号数组，由后端读取最新预设和职级计算；既有显式权重请求仍可使用。
- 打分关系 Excel 的空权重行在有部门预设时自动计算，否则均分；显式填写权重时保持人工配置。

## 验收

1. 示例 3:2:1 人数组合得到 30.00、20.00、10.00，合计 100.00。
2. 三位同职级人员得到确定性的 33.34、33.33、33.33。
3. 管理员可以保存和更新本授权子公司部门预设，不能读写未授权部门。
4. 职级可在新增、编辑、批量导入员工时设置，旧员工兼容默认值。
5. 已发布考核的评分任务和最终分不会因修改预设、职级而改变。
6. 本地演示数据补充部门及领导职级，并可重复执行，不覆盖非空部门或已有账号密码。

- 数据库迁移后核对旧员工默认职级、新预设唯一约束及已存权重。
- 页面在窄屏宽度下可编辑职级、系数并预览权重。
